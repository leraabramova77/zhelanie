# История версий

## 3.1.0 — 2026-10-11

- Вход по логину и паролю вместо GitHub: регистрация по коду школы, первый зарегистрированный — президент.
- Смена своего пароля, временный пароль от модератора/президента.
- Вкладка «Президент» в модерации: код школы и рассылка.

## 3.0.0 — 2026-10-11

- Переезд на Supabase (база, вход через GitHub, Edge Function для push, pg_cron) — своего сервера больше нет.
- Статическая сборка Next.js под GitHub Pages, CI/CD через GitHub Actions.
- Одно желание в неделю на ученика.
- Модерация: фильтр запретных слов, жалобы с автоскрытием, очередь, журнал, блокировки.
- Ранги: ученик, модератор, президент.
- Архитектура Feature-Sliced Design, Zustand, TanStack Query, линтер/форматтер Biome.
- Тесты бизнес-логики на PGlite (32 сценария).

## 2.0.0

- Next.js + TypeScript, Auth.js, Neon Postgres, Vercel Cron (не выкладывалась).

## 1.0.0

- Первая версия: Express + JSON-файл, анонимное голосование по устройству, push-напоминания.
