# Журнал решений

Новые решения — сверху. Формат: что решили → почему → чем пожертвовали.

## 2026-10-11 · ИИ-модератор и «Лучшие по мнению ИИ»

- **Что:** модель `dots-studio/dots-3-note-preview:free` (OpenRouter) проверяет каждое желание: удаляет мат,
  оскорбления, мемы, бессмыслицу, спам и не относящееся к предложениям; остальным ставит оценку 1–10.
- **Как:** один запрос на желание (и проверка, и оценка) — бесплатная модель ограничена по числу запросов.
  Триггер после вставки шлёт pg_net-запрос в Edge Function `ai`; cron добирает пропущенное.
- **Почему «скрыть», а не удалить насовсем:** ИИ ошибается; модератор видит удалённое ИИ и может вернуть.
- **Цена:** бесплатная модель может быть медленной или недоступной — тогда желание просто ждёт людей.
  Ключ API только в секретах Supabase — в коде сайта его нет.

## 2026-10-11 · Вход по логину и паролю вместо GitHub

- **Почему:** GitHub есть не у всех школьников.
- **Как:** логин + пароль в Supabase Auth; аккаунт создаёт Edge Function `account` (публичная регистрация выключена),
  нужен код школы. Первый зарегистрированный становится президентом. Аккаунт Леры (вошла через GitHub) переведён
  на логин `lera` с сохранением роли.
- **Цена:** нет восстановления пароля по почте — временный пароль выдаёт модератор/президент. Один человек может
  завести несколько аккаунтов, если знает код; смягчаем кодом школы, лимитом регистраций и модерацией.

## 2026-10-11 · Прод: существующий проект Supabase Леры и GitHub App для входа

- **Проект:** токен Supabase не позволял создавать новые проекты, поэтому используем существующий проект Леры
  (регион Сидней). Наши таблицы не пересекаются с её таблицами `classes`/`homework`/`users`.
  **Цена:** задержка из России выше, чем у Франкфурта. При желании позже переехать: создать проект в eu-central-1
  и прогнать `supabase/schema.sql` и `supabase/cron.sql`.
- **Вход:** вместо OAuth App — GitHub App, созданный через manifest flow: Лере достаточно нажать одну кнопку,
  ключи забираются автоматически.
- **Ссылка:** репозиторий переименован в `zhelanie` → https://leraabramova77.github.io/zhelanie/.

## 2026-10-11 · Своего сервера нет: логика в Supabase, сайт — статика

- **Почему:** доступа к Vercel пока нет (нужна проверка телефона), а GitHub Pages умеет только статику.
  Supabase даёт базу, вход, функции и cron бесплатно.
- **Как:** вся бизнес-логика и проверки прав — в SQL-функциях `security definer`, таблицы закрыты RLS.
  Push — Edge Function, расписание — pg_cron.
- **Цена:** логика на SQL/plpgsql, а не на TypeScript; для проверки — тесты на PGlite.
- **Плюс:** тот же сайт без изменений можно выложить на Vercel или любой статический хостинг.

## 2026-10-11 · Вход через GitHub OAuth (Supabase Auth)

- **Почему:** так попросили; не нужно хранить пароли; один голос на аккаунт.
- **Цена:** у ученика должен быть GitHub-аккаунт. Позже можно добавить Google или вход по почте в Supabase Auth
  без изменения логики.

## 2026-10-11 · Одно желание в неделю, три ранга, система модерации

- Одно желание — чтобы ученики выбирали лучшую идею, а не заваливали доску.
- Ранги «ученик / модератор / президент»: модераторов назначает только президент.
- Модерация: фильтр слов → жалобы с автоскрытием → решение модератора → журнал. Подробно в [moderation.md](moderation.md).

## 2026-10-11 · Feature-Sliced Design, Zustand, TanStack Query, Biome

- FSD — понятные границы фич для роста проекта. Корневые `app/`/`pages/` убраны; маршруты Next.js — файлы `*.next.tsx`
  в `src/app` (см. [architecture.md](architecture.md)).
- TanStack Query — серверные данные, Zustand — состояние интерфейса.
- Biome — линтер и форматтер в одной быстрой утилите.
