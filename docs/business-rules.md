# Бизнес-правила

Все правила реализованы в базе: [supabase/schema.sql](../supabase/schema.sql). Числа настраиваются в таблице
`app_settings` без изменения кода.

## Неделя

| Правило | Значение | Где |
|---|---|---|
| Часовой пояс | `Europe/Moscow` | `app_settings.time_zone` |
| Начало недели | понедельник 00:00 | `current_week()` |
| Конец голосования | воскресенье 23:59:59 (= понедельник 00:00) | `voting_deadline()` |
| Id недели | дата понедельника, `YYYY-MM-DD` | `posts.week_id` |

## Аккаунты

- Вход по **логину и паролю**. Почта, телефон и сторонние сервисы не нужны.
- Логин: 3–20 символов, латиница, цифры, `.` `-` `_`; без учёта регистра; уникальный.
- Имя: 2–40 символов, видно только самому ученику и модераторам (желания публикуются анонимно).
- Пароль: от 6 символов.
- **Регистрация только с кодом школы** (`app_settings.school_code`). Код задаёт и меняет президент; смена кода
  не мешает входить уже зарегистрированным. Пустой код — регистрация открыта всем.
- Самостоятельная регистрация в Supabase выключена — аккаунт создаёт только Edge Function `account` после проверок
  (код, логин, имя без мата, не больше 60 регистраций в час с одного IP).
- **Первый зарегистрированный, когда президента ещё нет, становится президентом.**
- Забыл пароль → модератор (для учеников) или президент (для учеников и модераторов) выдаёт временный пароль
  в «Модерация → Люди». Сменить пароль — кнопка «Пароль» в шапке.
- Внутри Supabase аккаунт хранится как `<логин>@zhelanie.local` — этот адрес никто не видит, писем туда нет.

## Желания

- Длина: 3–200 символов, пробелы схлопываются.
- **Лимит: 1 желание на ученика в неделю** (`app_settings.max_posts_per_week`).
- Дубликаты в рамках недели запрещены без учёта регистра: «Такое желание уже есть — поддержи его лайком!».
- Запрещены ссылки (`http`, `www.`, `t.me/`, домены `.ru/.com/.net/.org/.рф/.io/.me/.su`).
- Каждое желание проверяет ИИ-модератор и может удалить его (см. [moderation.md](moderation.md#ии-модератор)).
- Запрещены слова из списка запретных (см. [moderation.md](moderation.md#фильтр-запретных-слов)).
- Заблокированный ученик не может предлагать желания.
- Автор может удалить своё желание текущей недели (и предложить другое).
- Автор желания на сайте не показывается — только модераторам.

## Голосование

- 👍 = +1, 👎 = −1. Один голос на желание от аккаунта; повторное нажатие снимает голос.
- Голосовать можно только за желания текущей недели и только после входа.
- Заблокированный ученик голосовать может.
- Скрытые жалобами желания не видны и за них нельзя голосовать.

## Рейтинг и победитель

Сортировка «Популярные» и выбор победителя одинаковые:

1. больше `лайки − дизлайки`;
2. при равенстве — больше лайков;
3. при равенстве — раньше предложено.

«Лидирует» показывается, только если у первого места лайков больше, чем дизлайков.

Победитель фиксируется в `winners` автоматически после конца недели (`maintain()`): в понедельник 00:05 по cron и
при каждом открытии сайта. Скрытые желания в победители не попадают.

## Очистка

- Желания недели удаляются через **10 дней** после её начала (`app_settings.cleanup_days`, ≈ 1,5 недели) —
  то есть в четверг следующей недели. До этого прошлая неделя видна в карточке победителя (топ‑4).
- Вместе с желаниями удаляются их голоса и жалобы.
- Хранятся последние **12** победителей (`app_settings.history_size`).

## Уведомления

| Когда (МСК) | Текст |
|---|---|
| Понедельник 08:00 | «Новая неделя — новые желания! ✨ Победило: «…»» |
| Четверг 16:00 | «Не забудь проголосовать 🗳️» |
| Воскресенье 12:00 | «Последний день голосования! ⏰» |

- Подписаться можно без входа.
- Каждое напоминание уходит не больше одного раза за неделю (`sent_reminders`).
- «Мёртвые» подписки (браузер отписался) удаляются при рассылке.
- Президент может отправить уведомление всем вручную; это пишется в журнал.
- На iPhone push работает только если сайт добавлен на экран «Домой» (iOS 16.4+).
