# Система модерации

Модерация строится на четырёх уровнях защиты: автоматический фильтр → жалобы учеников → решения модераторов →
контроль президента. Всё, что делают модераторы, записывается в журнал.

## Ранги

| Возможность | Ученик | Модератор | Президент |
|---|:-:|:-:|:-:|
| Предлагать 1 желание в неделю, голосовать | ✅ | ✅ | ✅ |
| Пожаловаться на чужое желание | ✅ | — (сразу удаляет) | — |
| Удалить своё желание | ✅ | ✅ | ✅ |
| Удалить чужое желание (с причиной) | — | ✅ | ✅ |
| Разбирать очередь жалоб, «оставить» скрытое | — | ✅ | ✅ |
| Вести список запретных слов | — | ✅ | ✅ |
| Блокировать / разблокировать учеников | — | ✅ | ✅ |
| Выдать временный пароль ученику | — | ✅ | ✅ |
| Выдать временный пароль модератору | — | — | ✅ |
| Смотреть журнал модерации | — | ✅ | ✅ |
| Назначать и снимать модераторов | — | — | ✅ |
| Рассылка уведомления всем | — | — | ✅ |
| Менять код школы для регистрации | — | — | ✅ |

- Модератор **не может** назначать модераторов, блокировать модераторов и президента.
- Президента нельзя заблокировать или понизить через сайт.
- Президентом становится первый зарегистрированный. Сменить президента — SQL в Supabase:
  `update profiles set role = 'president' where login = 'новый'; update profiles set role = 'member' where login = 'старый';`

## Фильтр запретных слов

Срабатывает при отправке желания — такое желание просто не публикуется.

Как работает сравнение (`normalize_text`, `find_banned_word`):

1. Текст приводится к строчным, `ё` → `е`.
2. Латинские буквы-двойники и цифры заменяются кириллицей: `a c e h k m o p t x y 0 3 6 @` → `а с е н к м о р т х у о з б а`.
   Поэтому `xуй`, `XУЙ`, `x7` ловятся так же, как кириллица.
3. Повторы схлопываются: `хууууй` → `хуй`.
4. Цепочки одиночных букв склеиваются: `х у й`, `х.у.й` → `хуй`.
5. Слово ищется **внутри** каждого слова текста («мудак» найдёт «мудаки», «охуеть» — по корню «хуе»).
6. Если слово в списке начинается с `^` — ищется **только в начале** слова: `^бля` поймает «блять», но не «рубля».

Стартовый список (≈40 корней мата и оскорблений, плюс `х7`) создаётся при первой установке. Дальше список ведут
модераторы в разделе «Запретные слова». Удалённые из списка слова сами не возвращаются.

Как добавлять слова без ложных срабатываний:
- короткие корни, которые встречаются внутри обычных слов, добавляйте с `^`;
- проверьте на обычных словах: «хлебать» содержит «ебат», поэтому такой корень в список не добавлен.

## Жалобы

- Ученик выбирает причину: **мат, оскорбление, спам, не по теме, другое**.
- Одна жалоба от одного ученика на желание; на своё жаловаться нельзя; заблокированный жаловаться не может.
- После **3 жалоб** (`app_settings.report_hide_threshold`) желание автоматически **скрывается** для всех и попадает
  в очередь модерации.
- Модератор решает:
  - **Оставить** — желание возвращается, жалобы сбрасываются, и больше оно по жалобам не скрывается (защита от
    «массовых» жалоб на неугодное желание).
  - **Удалить** — с выбором причины.
- В очереди также видны нескрытые желания, на которые уже есть жалобы.

## Блокировка

- Заблокированный ученик не может предлагать желания и жаловаться, но может голосовать.
- Блокировать можно только учеников. При назначении модератором блокировка снимается.

## Журнал

Пишется в `mod_log` и показывается во вкладке «Журнал» (последние 50 записей):
удаление чужого желания (текст, причина, автор), «оставить» после жалоб, добавление/удаление запретного слова,
смена роли, блокировка/разблокировка, выдача временного пароля, смена кода школы, рассылка.
