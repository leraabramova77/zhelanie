# Желание недели

Школьный сайт: ученики предлагают желания («каждую пятницу — свободная форма»), лайкают и дизлайкают их,
а в воскресенье в 23:59 выбирается победитель — с ним школьный совет идёт к учителям.

**Сайт:** https://leraabramova77.github.io/zhelanie/

- Одно желание в неделю на ученика, вход через GitHub
- Модерация: фильтр мата, жалобы, модераторы и президент
- Push-напоминания проголосовать
- Мобильная вёрстка, тёмная тема

## Быстрый старт

```bash
npm install
cp .env.example .env.local   # ключи Supabase
npm run dev
```

## Команды

| Команда | Что делает |
|---|---|
| `npm run dev` | Локальный сервер разработки |
| `npm run build` | Статическая сборка в `out/` |
| `npm run lint` / `npm run format` | Biome: проверка / автоисправление |
| `npm run typecheck` | TypeScript |
| `npm run test:sql` | Тесты бизнес-логики базы (PGlite) |
| `npm run check` | Всё вместе |
